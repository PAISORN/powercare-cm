# UI Requirements

## Asset Tree
แสดง:
Site -> System -> Main Asset -> Sub-Asset -> Part

ห้าม:
- แสดง Asset Type เป็น folder ใน Tree
- แสดง Instrument เป็น root System
- แสดง Zone เป็น hierarchy level

## Create/Edit Form
- Asset Name
- Asset Code
- Asset Level
- Parent Asset
- System
- Area / Zone
- Asset Type
- Discipline
- Tag / KKS
- Manufacturer
- Model
- Serial No.
- Criticality
- Status
- Key Specification

## Parent Selector
- Main Asset: เลือก System, ไม่ต้องมี parent Asset
- Sub-Asset: parent เฉพาะ Main Asset
- Part: parent เป็น Main Asset หรือ Sub-Asset

## Search
Asset Name, Asset Code, Tag/KKS, Serial No., Manufacturer, Model

## Filters
Site, System, Area, Asset Level, Asset Type, Discipline, Status, Criticality

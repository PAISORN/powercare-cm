# Release Annual PM schedules through the existing Daily PM Plan

A Daily PM Release Batch reuses the confirmed PM Plan for the same Site and date when one exists, or creates that confirmed Daily PM Plan and its permanent numbering when none exists. The batch records selected Annual Schedule entries, reasoned Asset exclusions, and one Annual source link per generated PM Work; overlapping System or Zone targets therefore create one PM Work per Asset while retaining every source schedule.

An unreleased legacy Draft on the date blocks Annual release until the planner confirms or removes it. This avoids silently merging mutable PM Group selection into an immutable Annual Asset snapshot. Existing legacy PM Groups, snapshots, and work history remain unchanged, while PM Calendar and PM History label the resulting records as Annual or Legacy.
